# Fiche runtime — LangGraph / LangChain Python derrière API AnSu

> Statut : brouillon collaboratif. LangSmith peut être utilisé en debug développement pour inspecter les runs LangGraph, mais n’est pas considéré comme solution observability/evals de production à ce stade.

## 1. Cadrage

Runtime testé : LangGraph comme runtime stateful/orchestration, LangChain comme bibliothèque de modèles/tools/parsers, exposé derrière une API FastAPI compatible façade AnSu.

Objectif : reproduire un POC comparable à Mastra sur les questions runtime `A*`, sans valider LangSmith comme brique observability finale.

## 3. Garde-fou LangSmith

LangSmith peut être utilisé pour vérifier rapidement les traces LangGraph en développement : nodes, tool calls, messages, erreurs, latence. Cela ne valide pas LangSmith comme outil observability/evals final, car le self-hosted est documenté comme add-on Enterprise et les contraintes souveraineté/coût/export restent à clarifier.

## 4. Points à reprendre si LangSmith passe en shortlist observability

- Vérifier le mapping du coût réel Albert variable dans la colonne `Cost` native LangSmith : pricing map, `usage_metadata.total_cost` sur le run LLM, `update_run`, wrapper LLM custom. Pour l’instant : coût/impacts Albert visibles via champs AnSu custom ; `Cost` natif alimentable via pricing map / valeur actuelle `0.0`.

## 5. Note comparative Mastra / LangGraph — correction de lecture

Après vérification de la documentation Mastra, la différence Mastra/LangGraph ne doit pas être formulée comme “LangGraph sait gérer les workflows complexes, Mastra non”. Mastra supporte aussi de nombreux patterns avancés via Agents, Processors et Workflows : input/output processors, guardrails, retry, scorers, workflow branching/parallel/loops, nested workflows, human-in-the-loop, suspend/resume, snapshots/time travel.

La différence pertinente est plutôt :

```txt
Mastra = orchestration agentique haut niveau, batteries-included, DX produit TypeScript.
LangGraph = graphe d’état explicite, contrôle bas niveau, debug LangSmith très détaillé, DX Python expert.
```

LangGraph reste intéressant si AnSu veut modéliser explicitement une machine d’état agentique côté Python. Mastra reste très crédible pour workflows avancés avec meilleure proximité produit TypeScript.
